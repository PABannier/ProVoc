# ProVoc features

One line per feature. A box is ticked only when the named automated test passes and
exercises the feature through the real application UI.

Test names are `Target/Class/method`:

- `ProVocUITests/…` are XCUITest tests: a separate process sends real key events to the application.
- `ProVocTests/…` run inside the application: key events are posted to its event queue
  (they travel through `-[ProVocApplication sendEvent:]`, key equivalents, the field
  editor…) and the visible state is checked.
- A scenario of `ProVocInterrogationTests` named `X` exists twice: `testXInSheet`
  ("Dim test background" off, the test panel is a sheet) and `testXInDimmedModalPanel`
  ("Dim test background" on, the test panel is an application-modal floating panel).
  Both must pass; the lines below name the scenario as `testX*`.

Notes on behaviour that differs from the wording of the specification are given under the item.
